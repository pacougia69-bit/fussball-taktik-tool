Kurzanleitung: Digitales Taktik-Board

1. Spieler & Ball bewegen

  • Aufstellen: Spieler-Hexagone und den Ball mit gedrückter linker Maustaste (oder dem Finger auf dem Tablet) an die gewünschte Position auf dem Feld ziehen.
  • Namen & Nummern ändern: Ein Doppelklick auf einen Spieler öffnet das Bearbeitungsfenster. Name und Rückennummer eingeben und auf „Speichern“ klicken.

2. Laufwege & Pässe zeichnen

  1. Unten in der Steuerungsleiste auf den Button 🎯 Pfeile klicken (wird rot).
  2. Den gewünschten Modus wählen:
    • Modus: Laufweg (Grau) zeichnet eine durchgezogene blaue Linie für Laufwege der Spieler.
    • Modus: Pass (Orange) (einmal anklicken, wird orange) zeichnet eine gestrichelte orangefarbene Linie für den Ballweg oder Pässe.
  3. Mit gedrückter Maustaste den Pfeil auf dem Feld von Start zu Ziel ziehen.
  4. Einzelne Pfeile löschen: Mit der rechten Maustaste (Rechtsklick) direkt auf einen Pfeil klicken. Er verschwindet sofort einzeln. (Auf dem Tablet: Den Finger kurz auf dem Pfeil gedrückt halten).

3. Visuelle Hilfen (Zonen)

Mit dem Button 🗺️ Zonen lassen sich strategische Raster auf den Rasen legen (z. B. Flügel- und Halbräume oder Strafraum-Sektoren), um Räume ohne viele Worte verständlich zu machen.

4. Szenarien verwalten & sichern

  • 💾 Speichern: Nach jeder Änderung (Spieler verschoben, Pfeile gezeichnet, Zone gewählt) unten auf „Speichern“ klicken. Das Board merkt sich den Zustand fest für dieses Bild.
  • ➕ Bild kopieren / 🗑️ Löschen: Kopiert das aktuelle Szenario mitsamt allen Spielern und Pfeilen für die nächste Spielphase oder löscht das aktuelle Bild komplett.
  • Sicherung (Export / Import):
    Klicke auf 📥 Exportieren, um die Taktik als kleine Datei abzuspeichern.
    Über 📤 Importieren kann diese Datei auf jedem PC oder Board wieder hochgeladen werden, um den exakten Stand sofort wiederherzustellen.
